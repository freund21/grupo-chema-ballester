Contenedor 20' Open Side One Way

Ver página actual
NuevoNo disponible

El contenedor Open Side One Way permite el acceso lateral por ambos extremos.
Los contenedores Open Side One Way son perfectos para aquellas cargas que necesitan de una carga y descarga por el lateral del contenedor.
Este tipo de container abierto es ideal para transportar mercancías muy largas, cuyas dimensiones impiden que se pueda cargar por la puerta trasera.
Festivales, ferias y eventos utilizan muy a menudo este tipo de contenedores.
